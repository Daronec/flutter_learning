# React content store

Это независимое контентное хранилище для будущего React-приложения.

## Структура

- `catalog.json` — метаданные и порядок глав.
- `chapters/<chapter-id>/lessons.json` — метаданные уроков главы.
- `chapters/<chapter-id>/content/*.md` — исходное содержимое уроков.

Текст урока намеренно остаётся в Markdown. React сможет отображать его через
обычный Markdown-рендерер с поддержкой таблиц, блоков кода и подсветки синтаксиса.

## Генерация

Хранилище создано из существующей директории `knowledge/` командой:

```text
node scripts/migrate-content.mjs
```

Старые материалы не изменяются. Для проверки целостности миграции используется:

```text
node scripts/validate-content.mjs
```

Идентификаторы уроков основаны на исходных именах файлов и должны оставаться
стабильными после подключения React-навигации и поиска.
