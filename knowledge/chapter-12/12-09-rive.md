# Rive — интерактивные анимации

## Введение

Rive (ранее Flare) — это платформа для создания интерактивных анимаций. В отличие от Lottie, Rive поддерживает state machines, что позволяет создавать анимации, реагирующие на действия пользователя.

## Преимущества Rive

- **Интерактивность** — анимации реагируют на ввод
- **State Machines** — логика состояний в редакторе
- **Адаптивность** — анимации подстраиваются под размер
- **Кроссплатформенность** — одна анимация для всех платформ
- **Малый размер** — оптимизированные .riv файлы

## Базовое использование

### Загрузка анимации

```dart
class RiveExample extends StatelessWidget {
  const RiveExample({super.key});

  @override
  Widget build(BuildContext context) {
    return RiveAnimation.asset(
      'assets/animations/button.riv',
      // Размеры
      width: 200,
      height: 200,
      // Способ заполнения
      fit: BoxFit.contain,
      // Анимация по умолчанию
      artboard: 'Main',
      // Состояние загрузки
      onInit: (artboard) {
        print('Rive animation loaded!');
        // Получение контролов
        final stateMachine = artboard.findStateMachine('Button');
        if (stateMachine != null) {
          final input = stateMachine.findInput<bool>('Is Hovered');
          input?.value = true;
        }
      },
    );
  }
}
```

### Загрузка из network

```dart
RiveAnimation.network(
  'https://rive.app/community/animation.riv',
  width: 200,
  height: 200,
  fit: BoxFit.contain,
)
```

### Загрузка из bytes

```dart
final bytes = await rootBundle.load('assets/animations/animation.riv');
final artboard = Artboard.fromBytes(bytes.buffer.asUint8List());

RiveAnimation.artboard(
  artboard,
  width: 200,
  height: 200,
)
```

## RiveAnimation Widget

### Типы RiveAnimation

| Метод | Источник |
|-------|----------|
| `RiveAnimation.asset()` | Локальный файл |
| `RiveAnimation.network()` | URL |

### Параметры

| Параметр | Тип | Описание |
|----------|-----|----------|
| `src` | `String` | Путь к .riv файлу |
| `artboard` | `String?` | Имя artboard |

## State Machines

### Создание State Machine в Rive Editor

State Machine определяет логику анимации:

```
┌──────────────────────────────────────┐
│              State Machine            │
│                                      │
│  ┌─────────┐    ┌─────────┐         │
│  │  Idle   │───>│  Hover  │         │
│  └─────────┘    └─────────┘         │
│     ^               |                │
│     |               v                │
│  ┌─────────┐    ┌─────────┐         │
│  │  Press  │<───│  Active │         │
│  └─────────┘    └─────────┘         │
│                                      │
│  Inputs: IsHovered, IsPressed        │
└──────────────────────────────────────┘
```

### Управление State Machine из кода

```dart
class InteractiveRiveExample extends StatefulWidget {
  const InteractiveRiveExample({super.key});

  @override
  State<InteractiveRiveExample> createState() =>
      _InteractiveRiveExampleState();
}

class _InteractiveRiveExampleState
    extends State<InteractiveRiveExample> {
  bool _isHovered = false;
  bool _isPressed = false;

  void _onInit(Artboard artboard) {
    // Получаем State Machine
    final stateMachine =
        artboard.findStateMachine('Button State Machine');
    if (stateMachine == null) return;

    // Получаем входы
    final isHoveredInput =
        stateMachine.findInput<bool>('Is Hovered');
    final isPressedInput =
        stateMachine.findInput<bool>('Is Pressed');

    // Обновляем значения
    isHoveredInput?.value = _isHovered;
    isPressedInput?.value = _isPressed;
  }

  @override
  Widget build(BuildContext context) {
    return GestureDetector(
      onTapDown: (_) => setState(() => _isPressed = true),
      onTapUp: (_) => setState(() => _isPressed = false),
      onTapCancel: () => setState(() => _isPressed = false),
      onHover: (_) => setState(() => _isHovered = _isHovered),
      child: RiveAnimation.asset(
        'assets/animations/button.riv',
        stateMachines: ['Button State Machine'],
        onInit: _onInit,
        width: 200,
        height: 200,
      ),
    );
  }
}
```

## Animation Controller

### Управление анимациями

```dart
class RiveAnimationControllerExample extends StatefulWidget {
  const RiveAnimationControllerExample({super.key});

  @override
  State<RiveAnimationControllerExample> createState() =>
      _RiveAnimationControllerExampleState();
}

class _RiveAnimationControllerExampleState
    extends State<RiveAnimationControllerExample> {
  late RiveAnimationController _controller;

  @override
  void initState() {
    super.initState();
    // Создание контроллера
    _controller = RiveAnimationController(
      // Имя анимации в Rive файле
      animations: ['Idle', 'Loading', 'Success'],
      // Автозапуск
      autoPlay: true,
      // Повтор
      onInit: (artboard) {
        // Переключение анимаций
        // artboard.findSMI('Animation')?.value = 1.0;
      },
    );
    super.initState();
  }

  @override
  void dispose() {
    _controller.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return Column(
      children: [
        RiveAnimation.asset(
          'assets/animations/multiple.riv',
          controllers: [_controller],
          width: 200,
          height: 200,
        ),
        const SizedBox(height: 20),
        Row(
          mainAxisAlignment: MainAxisAlignment.spaceEvenly,
          children: [
            ElevatedButton(
              onPressed: () => _controller.play('Idle'),
              child: const Text('Idle'),
            ),
            ElevatedButton(
              onPressed: () => _controller.play('Loading'),
              child: const Text('Loading'),
            ),
            ElevatedButton(
              onPressed: () => _controller.play('Success'),
              child: const Text('Success'),
            ),
          ],
        ),
      ],
    );
  }
}
```

### Методы RiveAnimationController

| Метод | Описание |
|-------|----------|
| `play(name)` | Воспроизвести анимацию |
| `stop()` | Остановить |
| `dispose()` | Освободить ресурсы |

## Rive в интерактивных виджетах

### Кнопка с Rive

```dart
class RiveButton extends StatefulWidget {
  final VoidCallback? onPressed;
  final Widget child;

  const RiveButton({
    super.key,
    this.onPressed,
    required this.child,
  });

  @override
  State<RiveButton> createState() => _RiveButtonState();
}

class _RiveButtonState extends State<RiveButton> {
  bool _isHovered = false;
  bool _isPressed = false;

  void _onInit(Artboard artboard) {
    final sm = artboard.findStateMachine('Button');
    if (sm == null) return;

    final hoverInput = sm.findInput<bool>('hover');
    final pressInput = sm.findInput<bool>('pressed');

    hoverInput?.value = _isHovered;
    pressInput?.value = _isPressed;
  }

  @override
  Widget build(BuildContext context) {
    return MouseRegion(
      onEnter: (_) => setState(() => _isHovered = true),
      onExit: (_) => setState(() => _isHovered = false),
      child: GestureDetector(
        onTapDown: (_) => setState(() => _isPressed = true),
        onTapUp: (_) => setState(() => _isPressed = false),
        onTapCancel: () => setState(() => _isPressed = false),
        onTap: widget.onPressed,
        child: Stack(
          alignment: Alignment.center,
          children: [
            RiveAnimation.asset(
              'assets/animations/button.riv',
              stateMachines: ['Button'],
              onInit: _onInit,
              width: 200,
              height: 60,
            ),
            widget.child,
          ],
        ),
      ),
    );
  }
}
```

## Создание анимаций в Rive Editor

1. **Скачайте Rive Editor** — [rive.app](https://rive.app/)
2. **Создайте новый файл** — выберите шаблон
3. **Добавьте арты** — импортируйте векторную графику
4. **Создайте State Machine** — добавьте состояния и переходы
5. **Настройте Inputs** — IsHovered, IsPressed и т.д.
6. **Экспортируйте** — .riv файл

## Лучшие практики

1. **Используйте State Machines** для интерактивности
2. **Оптимизируйте арты** — минимизируйте количество точек
3. **Используйте `stateMachines`** вместо анимаций для интерактивных элементов
4. **Кэшируйте Artboard** при повторном использовании
5. **Обрабатывайте ошибки** через `onError` callback
6. **Тестируйте на слабых устройствах** — сложные state machines могут быть дорогими
