# Что такое State? Локальное и глобальное состояние

## Введение

В Flutter **состояние (state)** — это любая информация, которая может считываться при отображении виджета и которая может изменяться в течение жизни виджета. Понимание состояния является фундаментальным для разработки приложений на Flutter.

> **Ключевая идея:** Если данные влияют на то, что отображается на экране, — это состояние.

## Определение состояния

Состояние в контексте Flutter — это набор данных, определяющих текущий вид приложения в конкретный момент времени. Это могут быть:

- Значения текстовых полей ввода
- Флаги видимости элементов интерфейса
- Данные, полученные с сервера
- Положение скроллера
- Выбранный элемент в списке

## Локальное состояние (Local State)

**Локальное состояние** — это данные, которые принадлежат и управляются внутри одного виджета. Оно не доступно извне и не влияет на другие части приложения.

### Когда использовать локальное состояние

- Данные нужны только в одном виджете
- Состояние не должно передаваться наверх по дереву
- Виджет сам управляет своими изменениями

### Пример: Локальное состояние

```dart
import 'package:flutter/material.dart';

class CounterWidget extends StatefulWidget {
  const CounterWidget({super.key});

  @override
  State<CounterWidget> createState() => _CounterWidgetState();
}

class _CounterWidgetState extends State<CounterWidget> {
  // Локальное состояние — только для этого виджета
  int _count = 0;

  void _increment() {
    setState(() {
      _count++;
    });
  }

  @override
  Widget build(BuildContext context) {
    return Column(
      mainAxisSize: MainAxisSize.min,
      children: [
        Text('Счётчик: $_count'),
        const SizedBox(height: 8),
        ElevatedButton(
          onPressed: _increment,
          child: const Text('Увеличить'),
        ),
      ],
    );
  }
}
```

В этом примере переменная `_count` доступна только внутри `_CounterWidgetState`. Никто за пределами этого класса не может прочитать или изменить её напрямую.

## Глобальное состояние (Global State)

**Глобальное состояние** — это данные, доступные из множества виджетов, расположенных в разных частях дерева виджетов. Оно управляется централизованно и может быть прочитано или изменено из любого места приложения.

### Когда использовать глобальное состояние

- Данные нужны в нескольких виджетах на разных уровнях дерева
- Виджеты не находятся в отношениях «родитель-потомок»
- Состояние должно быть общим для всего приложения (например, тема, пользователь)

### Пример: Глобальное состояние (упрощённо)

```dart
import 'package:flutter/material.dart';

// Глобальный менеджер состояния
class AppUser with ChangeNotifier {
  String _name = 'Гость';
  bool _isLoggedIn = false;

  String get name => _name;
  bool get isLoggedIn => _isLoggedIn;

  void login(String name) {
    _name = name;
    _isLoggedIn = true;
    notifyListeners(); // Уведомляем слушателей
  }

  void logout() {
    _name = 'Гость';
    _isLoggedIn = false;
    notifyListeners();
  }
}
```

## Сравнение локального и глобального состояния

| Характеристика | Локальное состояние | Глобальное состояние |
|---|---|---|
| **Область видимости** | Один виджет | Всё приложение или его часть |
| **Доступ** | Только изнутри виджета | Из любого виджета дерева |
| **Сложность** | Низкая | Высокая |
| **Производительность** | Высокая | Зависит от реализации |
| **Тестируемость** | Простая | Требует мок-объектов |
| **Примеры** | Счётчик, чекбокс | Тема, пользователь, корзина |

## Архитектурные уровни состояния

```
┌──────────────────────────────────────┐
│         Глобальное состояние          │
│  (User, Theme, Cart, Settings)       │
│         ↓  Provider / Riverpod       │
├──────────────────────────────────────┤
│       Уровневое состояние             │
│  (Навигация, Tabs, PageController)   │
│         ↓  InheritedWidget           │
├──────────────────────────────────────┤
│         Локальное состояние           │
│  (TextField, Checkbox, Toggle)       │
│         ↓  setState                  │
└──────────────────────────────────────┘
```

## Примеры использования

### Пример 1: Локальное состояние — переключение темы в виджете

```dart
class ThemeToggle extends StatefulWidget {
  const ThemeToggle({super.key});

  @override
  State<ThemeToggle> createState() => _ThemeToggleState();
}

class _ThemeToggleState extends State<ThemeToggle> {
  bool _isDark = false;

  @override
  Widget build(BuildContext context) {
    return Card(
      child: ListTile(
        title: Text(_isDark ? 'Тёмная тема' : 'Светлая тема'),
        trailing: Switch(
          value: _isDark,
          onChanged: (value) {
            setState(() {
              _isDark = value;
            });
          },
        ),
      ),
    );
  }
}
```

### Пример 2: Глобальное состояние — данные пользователя

```dart
class ProfilePage extends StatelessWidget {
  const ProfilePage({super.key});

  @override
  Widget build(BuildContext context) {
    // Получаем глобальное состояние пользователя
    final user = context.watch<AppUser>();

    return Column(
      children: [
        Text('Привет, ${user.name}!'),
        ElevatedButton(
          onPressed: () => user.logout(),
          child: const Text('Выйти'),
        ),
      ],
    );
  }
}
```

## Когда использовать какое состояние

### Используйте локальное состояние, когда:

1. Данные используются в одном виджете
2. Изменение не влияет на другие части UI
3. Виджет может самостоятельно управлять своим состоянием

### Используйте глобальное состояние, когда:

1. Данные нужны в нескольких виджетах
2. Виджеты находятся далеко друг от друга по дереву
3. Состояние должно быть согласованным между разными экранами
4. Данные получены один раз и используются многими виджетами

## Best Practices

### ✅ Делайте

- Начинайте с локального состояния
- Поднимайте состояние только при необходимости
- Используйте наименее инвазивное решение
- Делите большие состояния на меньшие

### ❌ Не делайте

- Не создавайте глобальное состояние «на всякий случай»
- Не передавайте данные через конструкторы на 5+ уровней
- Не храните в глобальном состоянии то, что может быть вычислено
- Не смешивайте локальное и глобальное состояние в одном классе

## Заключение

Понимание разницы между локальным и глобальным состоянием — это первый шаг к эффективному управлению состоянием в Flutter. Всегда начинайте с самого простого решения и усложняйте только при необходимости.

> **Правило:** Если состояние нужно только в одном виджете — используйте `StatefulWidget` с `setState()`. Если состояние нужно многим виджетам — используйте Provider, Riverpod или BLoC.
