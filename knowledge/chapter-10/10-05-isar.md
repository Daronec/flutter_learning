# Isar — высокопроизводительная база данных

Isar — это высокопроизводительная NoSQL база данных, написанная на Dart. Она оптимизирована для скорости и использует кэширование в памяти для молниеносных запросов.

## Установка

```yaml
dependencies:
  isar: ^3.1.0+1
  isar_flutter_libs: ^3.1.0+1

dev_dependencies:
  isar_generator: ^3.1.0+1
  build_runner: ^2.4.8
```

```bash
flutter pub add isar isar_flutter_libs
flutter pub add --dev isar_generator build_runner
```

## Инициализация

### Настройка Isar

```dart
import 'package:isar/isar.dart';
import 'package:isar_flutter_libs/isar_flutter_libs.dart';

part 'user.g.dart';
part 'isar_database.g.dart';

// Открытие базы данных
Future<Isar> openDatabase() async {
  if (Isar.instanceNames.isEmpty) {
    return await Isar.open(
      [UserSchema],
      directory: 'isar_db',
    );
  }
  return Isar.getInstance()!;
}
```

## Определение схем

### Модель данных

```dart
@Collection()
class User {
  Id id = 0; // Поле id (первичный ключ)

  @Index(type: IndexType.fulltext)
  late String name;

  late String email;

  int? age;

  late bool isActive;

  @Backlink(to: 'user')
  final tasks = IsarList<Task>();

  DateTime? createdAt;
}

@Collection()
class Task {
  Id id = 0;

  late String title;

  bool isDone = false;

  late int userId;

  final user = IsarLink<User>();

  DateTime? createdAt;
}
```

## CRUD-операции

### Создание записей

```dart
final isar = await openDatabase();

// Создать одну запись
final userId = await isar.users.put(
  User()
    ..name = 'Иван Петров'
    ..email = 'ivan@example.com'
    ..age = 25
    ..isActive = true,
);

// Создать несколько записей
await isar.users.putAll([
  User()
    ..name = 'Мария'
    ..email = 'maria@example.com'
    ..age = 30
    ..isActive = true,
  User()
    ..name = 'Алексей'
    ..email = 'alex@example.com'
    ..age = 28
    ..isActive = false,
]);

// Создать с ID
await isar.users.put(User()
  ..id = 42
  ..name = 'С конкретным ID'
  ..email = 'custom@example.com',
);
```

### Чтение записей

```dart
// Получить по ID
User? user = await isar.users.get(userId);

// Получить все записи
List<User> allUsers = await isar.users.where().findAll();

// Фильтрация
List<User> adults = await isar.users
    .where()
    .ageEqualTo(18) // age >= 18
    .findAll();

// Несколько условий
List<User> results = await isar.users
    .where()
    .ageEqualTo(25)
    .and()
    .nameEqualTo('Иван')
    .findAll();

// Поиск по имени (LIKE)
List<User> ivanUsers = await isar.users
    .where()
    .nameContains('Иван')
    .findAll();

// Сортировка
List<User> sortedUsers = await isar.users
    .where()
    .sortByNameDesc()
    .findAll();

// Пагинация
List<User> page1 = await isar.users
    .where()
    .offset(0)
    .limit(20)
    .findAll();

// Подсчёт
int count = await isar.users.where().count();
```

### Обновление записей

```dart
// Обновить по ID
await isar.users.put(
  User()
    ..id = userId
    ..name = 'Обновлённое имя'
    ..email = 'ivan@example.com'
    ..age = 26,
);

// Обновить через фильтр
await isar.users
    .filter()
    .isActiveEqualTo(false)
    .forEach((user) {
  user.isActive = true;
});

// Обновить одно поле
final user = await isar.users.get(userId);
if (user != null) {
  user.name = 'Новое имя';
  await isar.users.put(user);
}
```

### Удаление записей

```dart
// Удалить по ID
await isar.users.delete(userId);

// Удалить все записи
await isar.users.deleteAll();

// Удалить по фильтру
await isar.users
    .filter()
    .isActiveEqualTo(false)
    .deleteAll();

// Удалить бокс
await isar.users.where().findAll();
```

## Связи между коллекциями

### One-to-One

```dart
@Collection()
class Profile {
  Id id = 0;

  late String bio;

  late int userId;

  final user = IsarLink<User>();
}

// Установка связи
final profile = Profile()
  ..bio = 'Flutter разработчик'
  ..userId = userId;

await isar.profiles.put(profile);
profile.user.value = await isar.users.get(userId);
```

### One-to-Many

```dart
// В User уже есть @Backlink
// final tasks = IsarList<Task>();

// Добавление задачи к пользователю
final task = Task()
  ..title = 'Изучить Isar'
  ..userId = userId;

await isar.tasks.put(task);

// Получение задач пользователя
final user = await isar.users.get(userId);
final tasks = user!.tasks.where((t) => !t.isDone).toList();
```

## Реактивное обновление (Streams)

```dart
// Stream всех пользователей
isar.users.where().watchAutoLoad().listen((users) {
  print('Пользователи: ${users.length}');
});

// Stream с фильтром
isar.users
    .filter()
    .isActiveEqualTo(true)
    .watchAutoLoad()
    .listen((activeUsers) {
  print('Активных пользователей: ${activeUsers.length}');
});

// Stream одной записи
isar.users
    .filter()
    .idEqualTo(userId)
    .watchSingle()
    .listen((user) {
  print('Пользователь: ${user?.name}');
});
```

### Использование с Flutter

```dart
class UserStreamWidget extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return IsarWidget(
      builder: (context, isar) {
        return StreamBuilder<List<User>>(
          stream: isar.users.where().watchAutoLoad(),
          builder: (context, snapshot) {
            if (!snapshot.hasData) {
              return const Center(child: CircularProgressIndicator());
            }

            final users = snapshot.data!;
            return ListView.builder(
              itemCount: users.length,
              itemBuilder: (context, index) {
                final user = users[index];
                return ListTile(
                  title: Text(user.name),
                  subtitle: Text(user.email),
                );
              },
            );
          },
        );
      },
    );
  }
}
```

## Best Practices

- **Используйте `Id`** — Isar автоматически генерирует ID
- **Используйте индексы** — для часто запрашиваемых полей
- **Используйте `watchAutoLoad()`** — для реактивного обновления UI
- **Используйте транзакции** — для связанных операций
- **Кэшируйте Isar-инстанс** — создавайте один экземпляр на приложение
- **Используйте `@Backlink`** — для навигации по связям
