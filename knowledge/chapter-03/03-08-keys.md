# 3.8 Key, ValueKey, UniqueKey — зачем нужны ключи

## Что такое Key?

Key — это идентификатор для виджетов, который помогает Flutter сопоставлять элементы при перестройке дерева.

### Когда Key нужны?

Key нужны когда:
- Виджеты вставляются/удаляются из дерева
- Виджеты меняются местами
- Виджеты с состоянием (StatefulWidget) в динамических списках

## Типы Key

### ObjectKey

Базовый класс для Key. Сравнивает объекты по ссылке.

```dart
ObjectKey(myObject); // Сравнивает по ==
```

### ValueKey

Сравнивает виджеты по значению.

```dart
// ValueKey срабатывает при равенстве значений
ValueKey<int>(1); // Key со значением 1
ValueKey<String>('user-123'); // Key со строкой

// Пример использования
ListView.builder(
  itemBuilder: (context, index) {
    return ListTile(
      key: ValueKey(users[index].id), // Уникальный ключ по ID
      title: Text(users[index].name),
    );
  },
)
```

### UniqueKey

Уникальный ключ, который гарантированно не повторяется.

```dart
// Каждый UniqueKey уникален
UniqueKey(); // Новый уникальный ключ

// Использование
// ❌ Не рекомендуется для списков (каждый раз новый!)
// ✅ Для создания временных виджетов
Dialog(
  key: UniqueKey(), // Каждый раз новый Dialog с новым ключом
  child: Text('Dialog'),
);
```

### GlobalKey

Глобальный ключ, видимый во всём дереве.

```dart
// GlobalKey виден во всём дереве виджетов
final globalKey = GlobalKey();

// Использование
Container(
  key: globalKey,
  child: Text('Hello'),
);

// Получение State из любого места
var state = globalKey.currentState as MyStatefulState;
state.doSomething();

// Получение RenderObject
var renderBox = globalKey.currentContext?.findRenderObject() as RenderBox;
```

## Как работает Key matching

### Без Key

```dart
// Widget Tree сравнение по типу и позиции
[
  Text('A'),  // index 0
  Text('B'),  // index 1
  Text('C'),  // index 2
]

// После удаления B:
[
  Text('A'),  // index 0 — совпал (тот же тип)
  Text('C'),  // index 1 — совпал (тот же тип) — НО это был Text('B')!
]
```

### С ValueKey

```dart
// С Key — сравнение по значению ключа
[
  Text('A', key: ValueKey('a')),
  Text('B', key: ValueKey('b')),
  Text('C', key: ValueKey('c')),
]

// После удаления B:
[
  Text('A', key: ValueKey('a')), // index 0 — совпал
  Text('C', key: ValueKey('c')), // index 1 — совпал по ключу 'c'
]
```

## Пример: ListView с Key

```dart
class MyList extends StatefulWidget {
  @override
  State<MyList> createState() => _MyListState();
}

class _MyListState extends State<MyList> {
  List<String> items = ['A', 'B', 'C'];
  
  @override
  Widget build(BuildContext context) {
    return ListView(
      children: items.map((item) {
        return ListTile(
          key: ValueKey(item), // Ключ по значению
          title: Text(item),
          trailing: IconButton(
            icon: Icon(Icons.delete),
            onPressed: () {
              setState(() => items.remove(item));
            },
          ),
        );
      }).toList(),
    );
  }
}
```

## Key и StatefulWidget

### Без Key — проблема

```dart
// ❌ Без Key: при удалении элемента, State перемешивается
// Удаляем элемент B, но State элемента B становится у элемента C!

// С Key: State привязан к ключу, а не к позиции
// Удаляем элемент B, его State удаляется, State элемента C остаётся
```

### Пример с сохранением состояния

```dart
class TodoList extends StatefulWidget {
  @override
  State<TodoList> createState() => _TodoListState();
}

class _TodoListState extends State<TodoList> {
  List<TodoItem> todos = [];
  
  @override
  Widget build(BuildContext context) {
    return ListView(
      children: todos.map((todo) {
        return TodoTile(
          key: ValueKey(todo.id), // Ключ по ID — состояние сохраняется
          todo: todo,
          onDelete: () => setState(() => todos.remove(todo)),
        );
      }).toList(),
    );
  }
}

class TodoTile extends StatefulWidget {
  final TodoItem todo;
  final VoidCallback onDelete;
  
  const TodoTile({required this.todo, required this.onDelete, super.key});
  
  @override
  State<TodoTile> createState() => _TodoTileState();
}

class _TodoTileState extends State<TodoTile> {
  bool _isCompleted = false;
  
  @override
  Widget build(BuildContext context) {
    return ListTile(
      title: Text(
        widget.todo.title,
        style: TextStyle(decoration: _isCompleted ? TextDecoration.lineThrough : null),
      ),
      trailing: Row(
        mainAxisSize: MainAxisSize.min,
        children: [
          IconButton(
            icon: Icon(_isCompleted ? Icons.check : Icons.check_border),
            onPressed: () => setState(() => _isCompleted = !_isCompleted),
          ),
          IconButton(
            icon: Icon(Icons.delete),
            onPressed: widget.onDelete,
          ),
        ],
      ),
    );
  }
}
```

## Когда использовать какой Key?

| Key | Когда использовать | Пример |
|---|---|---|
| **ValueKey** | Есть уникальное значение | `ValueKey(user.id)` |
| **UniqueKey** | Временные виджеты | Диалоги, тултипы |
| **GlobalKey** | Доступ из любого места | `GlobalKey<ScaffoldState>` |
| **ObjectKey** | Объект с `==` | `ObjectKey(myObject)` |

## GlobalKey — продвинутые примеры

### Доступ к Scaffold

```dart
final scaffoldKey = GlobalKey<ScaffoldState>();

@override
Widget build(BuildContext context) {
  return Scaffold(
    key: scaffoldKey,
    appBar: AppBar(...),
    body: Center(
      child: ElevatedButton(
        onPressed: () {
          scaffoldKey.currentState?.openDrawer();
        },
        child: Text('Open Drawer'),
      ),
    ),
  );
}
```

### Перемещение виджета

```dart
final widgetKey = GlobalKey();

// Виджет может быть перемещён в другую часть дерева
// сохранив своё состояние
Widget build(BuildContext context) {
  return Column(
    children: [
      if (showInTop)
        Container(key: widgetKey, child: Text('Moved')),
    ],
  );
}
```

## Best Practices

1. **ValueKey** — для списков с уникальными ID
2. **UniqueKey** — только для временных виджетов
3. **GlobalKey** — только когда действительно нужно
4. **Не используйте Key** для статических списков
5. **Используйте key** когда State может перемешаться

## Заключение

Key помогают Flutter правильно сопоставлять виджеты при перестройке дерева:
- **Без Key** — сопоставление по типу и позиции
- **С Key** — сопоставление по значению ключа
- **ValueKey** — самый распространённый тип для списков
- **GlobalKey** — для доступа к State/RenderObject из любого места
