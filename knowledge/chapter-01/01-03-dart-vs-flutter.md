# 1.3 Dart vs Flutter — в чём разница

## Ключевое различие

**Dart** и **Flutter** — это два разных, но тесно связанных продукта от Google:

| | Dart | Flutter |
|---|---|---|
| **Что это?** | Язык программирования | UI-фреймворк |
| **Роль** | Синтаксис, логика, алгоритмы | Создание пользовательского интерфейса |
| **Аналогия** | Как «C++» | Как «Qt» или «MFC» |
| **Использование** | Серверы (Dart Frog, Shelf), CLI-инструменты, скрипты | Мобильные, веб, десктоп приложения |

## Dart — язык программирования

Dart — это объектно-ориентированный язык программирования, разработанный Google в 2011 году.

**Возможности Dart без Flutter:**
- **Серверная разработка** — Dart Frog, Shelf, Aqueduct
- **CLI-инструменты** — командные строки, скрипты автоматизации
- **Генерация кода** — build_runner, код-генерация
- **Скрипты** — автоматизация задач

**Ключевые особенности языка:**
- Статическая типизация с null-safety
- garbage collection (автоматическое управление памятью)
- Асинхронность (async/await, Future, Stream)
- Generics, миксины, интерфейсы
- Компиляция в JIT (для разработки) и AOT (для релиза)

## Flutter — фреймворк для UI

Flutter — это UI-фреймворк, который *использует* Dart как язык программирования.

**Возможности Flutter:**
- Создание кроссплатформенных UI
- Собственный рендерер (Skia/Impeller)
- Готовые виджеты для мобильных, веб, десктоп
- Анимации, жесты, рисование
- Интеграция с нативным кодом

## Взаимосвязь

```
Dart (язык)                    Flutter (фреймворк)
─────────                      ─────────────────
main() {                       MaterialApp(
  runApp(MyApp());              home: Scaffold(
}                               body: Center(
                                  child: Text('Hello'),
                                ),
                              ),
                            );
```

- **Dart** — это язык, на котором пишется код
- **Flutter** — это библиотека (пакет), которую импортирует Dart-код для создания UI

## Можно ли использовать их по отдельности?

**Dart без Flutter:**
- ✅ Серверные приложения
- - CLI-утилиты
- - Скрипты и автоматизация
- - Веб-бэкенды

**Flutter без Dart:**
- ❌ Невозможно. Flutter написан на Dart и требует Dart для написания приложений

## Аналогии из других экосистем

| Пара | Язык | Фреймворк |
|---|---|---|
| Dart + Flutter | Dart | Flutter |
| C++ + Qt | C++ | Qt |
| C# + WPF | C# | WPF |
| JavaScript + React | JavaScript | React |
| Swift + SwiftUI | Swift | SwiftUI |
| Java + JavaFX | Java | JavaFX |

## Заключение

- **Dart** — это инструмент (язык программирования)
- **Flutter** — это применение (создание UI)
- Для разработки Flutter-приложений нужен Dart
- Dart можно использовать и без Flutter для других задач
