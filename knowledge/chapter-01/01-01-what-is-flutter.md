# 1.1 Что такое Flutter? История и философия Google

## Что такое Flutter?

Flutter — это UI-фреймворк с открытым исходным кодом, разработанный компанией Google для создания нативных приложений для мобильных, веб и десктоп-платформ из единой кодовой базы. Первый публичный релиз Flutter 1.0 состоялся в декабре 2018 года.

## История создания

- **2015**: Google начинает работу над проектом «Flutter» (кодовое название «Sky»), изначально для Android
- **2017**: Google I/O 2017 — первое публичное демонстрация
- **декабрь 2018**: Flutter 1.0 — стабильный релиз для iOS и Android
- **2019**: Поддержка веб (Flutter Web)
- **2020**: Поддержка десктоп-платформ (Windows, macOS, Linux)
- **2021**: Flutter 2.0 — стабильная поддержка всех платформ (stable cross-platform)
- **2022–2023**: Flutter 3.x — улучшенный рендерер Impeller, улучшенная производительность
- **2024+**: Flutter 3.16+ — продолжение улучшений производительности и новые возможности

## Философия Google

### Кроссплатформенность без компромиссов

Google стремится доказать, что кроссплатформенная разработка не должна уступать нативной в плане:
- **Производительности** — собственный рендерер Skia/Impeller рисует каждый пиксель
- **Внешнего вида** — идентичный UI на всех платформах
- **Доступа к API** — Platform Channels для взаимодействия с нативным кодом

### Declarative UI

Flutter следует парадигме декларативного UI (вдохновлённой React), где:
- UI описывается как функция текущего состояния
- При изменении состояния фреймворк автоматически перестраивает нужные части дерева
- Разработчик описывает *что* показывать, а не *как*

### «Write Once, Run Everywhere»

Одна кодовая база для всех платформ:
- **Мобильные**: iOS, Android
- **Веб**: браузеры
- **Десктоп**: Windows, macOS, Linux
- **Встраиваемые** (embedded)

## Преимущества Flutter

1. **Единая кодовая база** — снижение затрат на разработку и поддержку
2. **Hot Reload** — мгновенное отображение изменений без перезапуска
3. **Нативная производительность** — компиляция в машинный код (AOT для релиза, JIT для разработки)
4. **Богатая экосистема** — тысячи пакетов на pub.dev
5. **Сильная сообщество** — активное развитие и поддержка Google
6. **Fuchsia OS** — Flutter является основным UI-фреймворком для новой ОС Google

## Кто использует Flutter?

- **Google** — Google Ads, Google Pay, Google Assistant
- **BMW** — внутренние инструменты и клиентские приложения
- **Alibaba** — Xianyu (приложение для перепродажи товаров)
- **eBay** — интеграция Flutter в существующие приложения
- **Toyota** — приложение Entune 3.0
- **字节跳动 (ByteDance)** — приложение Taua

## Заключение

Flutter — это не просто фреймворк, это целая экосистема, которая меняет подход к кроссплатформенной разработке, доказывая, что один код может создавать качественные нативные приложения для всех платформ.
